# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/hritikhri/Vibemeet.git
```

```bash
cd Vibemeet
```

---

## Install Dependencies

### Backend

```bash
cd backend
npm install
```

### Frontend

```bash
cd frontend
npm install
```

---

# 🔑 Environment Variables

## Backend (.env)

```env
PORT=5000

MONGO_URI=your_mongodb_uri

JWT_SECRET=your_secret_key

REDIS_URL=your_redis_url

CLOUDINARY_CLOUD_NAME=

CLOUDINARY_API_KEY=

CLOUDINARY_API_SECRET=

EMAIL_USER=

EMAIL_PASS=

CLIENT_URL=http://localhost:5173
```

---

# ▶️ Run the Project

## Backend

```bash
cd backend
npm run dev
```

---

## Frontend

```bash
cd frontend
npm run dev
```
